# Prompt Engineering Assignment

## 📌 Overview

This assignment was completed as part of a **Prompt Engineering Workshop** organized by **Code Arena X**.

The workshop introduced practical applications of Prompt Engineering and AI-powered tools. As part of the assignment, I explored how AI can be used to build a personal portfolio and create short AI-generated videos.

## 🎯 Objectives

- Learn the fundamentals of Prompt Engineering
- Understand how to write effective AI prompts
- Explore AI-assisted website development
- Use **Antigravity** to build a personal portfolio
- Use **Google Flow** to generate a 10-second AI video
- Understand basic Prompt Security and AI Threat Awareness

## 🛠️ Tools Used

- **Google Flow** – AI video generation
- **Antigravity** – AI-assisted portfolio development
- **Prompt Engineering** – Prompt creation and optimization
- **GitHub** – Project documentation and submission

## 🌐 Portfolio

As part of the assignment, I created a personal portfolio website using AI-assisted development with Antigravity.

The portfolio includes:

- About Me
- Skills

- Contact Information

## 🎬 10-Second AI Video

I also created a **10-second AI-generated video using Google Flow**.
